# Architecture Decision Records

Decisions that outlive a single requirement: technology choices, integration
patterns, data ownership, cross-cutting conventions. Feature-local decisions
belong in that feature's `feature-doc.md` §9 instead.

- Template: [`../templates/adr.md`](../templates/adr.md)
- Naming: `NNNN-kebab-case-title.md`, four-digit sequential number
- Status flow: Proposed → Accepted → (Superseded by ADR-… | Deprecated)
- Never edit an Accepted ADR's decision; write a new one that supersedes it
